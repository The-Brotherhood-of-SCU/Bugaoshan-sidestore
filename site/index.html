怎么用

  1. 在 iPhone 上装好 SideStore（或 AltStore），并完成一次配对 / 登录你自己的 Apple ID。
  2. 点上面的「SideStore 添加」，或手动打开 SideStore → Sources → +，粘贴源地址。
  3. 中国大陆网络建议用「国内镜像」地址：JSON、图标、截图、IPA 都经由 gh-proxy.com 转发；直连地址需要能访问 GitHub。
  4. 在源里找到「不高山上」，安装即可；IPA 未签名，安装时由 SideStore 用你的证书重新签名。
  5. 源 JSON 会随上游自动更新，SideStore 里会出现新版本。

预览版与正式版是两份独立源、同一个 Bundle ID，同一时间只能装其中一个；切换渠道前先卸载旧版本。镜像源与直连源也是同一份版本内容，选一个加入即可，不必同时添加。

⚠️ 桌面课表小组件：本源的构建已内置 Keychain 桥接补丁。安装时请选 Keep App Extensions (Use Main Profile)，装完先打开一次 App，再添加小组件即可正常显示；移除扩展则小组件和实时活动都不可用。
